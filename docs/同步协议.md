# 同步协议（手环端「池鱼单词」 ↔ 手机端「池鱼手环同步」）

互连基于 Vela `@system.interconnect`，消息为 JSON 字符串，`tag` 字段区分消息类型。

## 握手

| 方向 | 消息 |
|---|---|
| 手机 → 手环 | `{"tag":"__hs__","count":0}` |
| 手环 → 手机 | `{"tag":"__hs__","count":1}` |
| 手机 → 手环 | `{"tag":"__hs__","count":2}` |

双方收齐 0→1→2 后视为连接建立（与喵喵电子书协议一致，保证兼容既有工具）。

## 手机 → 手环：推送词表（word_push，分块）

一条 BLE 消息体积有限，词表按 **20 词/块** 分块发送：

```json
{"tag":"word_push","batch":0,"total":5,"words":[{...}]}
{"tag":"word_push","batch":1,"total":5,"words":[{...}]}
...
```

- `batch`：块序号（从 0 开始）；`total`：总块数。
- 手环收齐所有块后按**单词覆盖**合并进本地词库（手机词表为准），并回：

```json
{"tag":"push_ack","count":100,"total":360}
```

- `count`：本次推入词数；`total`：手环词库总词数。

### 单词字段格式

```json
{
  "w": "apple",
  "m": "苹果",
  "e": 2.5,        // 难度系数 ease（1.3~3.0）
  "i": 1,          // 当前间隔（天）
  "lvl": 2,        // 熟练度 0~8
  "c": 5,          // 答对次数
  "wc": 1,         // 答错次数
  "next": 1760000000000  // 上次复习时间戳（毫秒）
}
```

手机端导出词表时带上每个词的 SRS 状态；手环直接使用，背完更新后随记录同步回手机。

## 手机 → 手环：请求收回学习记录（record_pull）

```json
{"tag":"record_pull"}
```

手环回复并清空本地记录：

```json
{"tag":"record_back","records":[
  {"word":"apple","action":"know","t":"2026-10-18 12:00:00"},
  {"word":"banana","action":"forget","t":"2026-10-18 12:05:30"}
]}
```

- `action`：`know`=认识（左滑）、`fuzzy`=模糊（上滑）、`forget`=不会（下滑）。
- `rt`：看单词到做出选择的**反应时间**（毫秒，可选）——反应快=熟、慢=生疏，算法据此调节复习间隔。
- `dwell`：在**释义页停留时间**（毫秒，可选）——停留久=认真学了、扫一眼=没细看，算法据此微调下次复习时机。
- 手环最多保留最近 500 条；发出后清空，避免重复回传。

## 手环端本地存储

统一存于 `internal://files/words/data.json`：

```json
{
  "words": [{ "w": "...", "m": "...", "e": 2.5, "i": 1, "lvl": 0, "c": 0, "wc": 0, "next": 0 }],
  "records": [{ "word": "...", "action": "know", "t": "2026-10-18 12:00:00" }]
}
```

## 手机端合并规则（池鱼Study 操控中心）

1. 按 `word` 定位，`t`（时间戳）去重（同一词同一秒的选择只算一次）。
2. 手环记录合并进手机 SRS：`know/fuzzy/forget` 对应手机 `update_word_learning` 的相应动作，更新间隔与熟练度。
3. 连续 2 次 `forget` 的词 → 自动加入「今日复习」。
4. 合并后弹通知提示：`本次回收 N 条 · 更新 M 个单词 · 新增 K 个待复习`。

## 本地直连（推荐：池鱼Study ↔ 伴生App 免文件互通）

池鱼Study 在手机内启动本地 HTTP 服务 `127.0.0.1:8765`（仅本机可达，不出网）：

| 接口 | 方法 | 说明 |
|---|---|---|
| `/health` | GET | 服务在线检查 `{ok:true, port:8765}` |
| `/api/wordlist?scope=due&count=50` | GET | 返回 `{version, words:[{w,m,e,i,lvl,c,wc,next}]}`（scope: due/low/new/all） |
| `/api/records` | POST | 接收 `{records:[{word,action,t}]}`，返回 `{merged, updated, new_due, bad}` |

**一键推送链路**：池鱼Study「🚀一键推送」→ `page.launch_url("chiyu-sync://push?scope=due&count=50")` 拉起伴生App → 伴生App 从 `/api/wordlist` 拉词表 → 按 `word_push` 协议推手环。

**记录回传链路**：伴生App 收回 `record_back` 后 → POST `/api/records` 自动合并（免导文件）；直连不可用时保存 `Download/Chiyu/` 文件兜底。
